코드톡 온라인 게임
인터넷 공개: GitHub 저장소에 이 ZIP의 압축을 푼 파일들을 업로드하고 Render(render.com)에서 New > Web Service로 연결합니다. Runtime Node, Build Command npm install, Start Command npm start를 지정합니다. 배포 후 제공되는 HTTPS 주소를 학생들에게 공유합니다. 무료 플랜 제공 여부와 조건은 서비스에서 확인하세요.
같은 교실 네트워크: Node.js 18 이상 설치 후 이 폴더에서 npm start 실행. 서버 PC는 http://localhost:8080, 다른 PC는 서버 PC의 IPv4 주소:8080으로 접속합니다. 방화벽과 학교 네트워크 정책에 따라 차단될 수 있습니다.
방장이 인원, 이름, 색상을 선택해 방을 생성합니다. 친구는 초대 링크 또는 방 코드로 접속합니다. 중복 색상은 선택을 변경해야 합니다. 모두 입장하면 방장이 가위바위보 결과 순서를 지정합니다. 게임 상태는 서버에서 공유되며 약 0.6초마다 갱신됩니다. 서버 재시작 시 방이 사라지며 새로고침 후 재접속 복구는 지원하지 않습니다.
